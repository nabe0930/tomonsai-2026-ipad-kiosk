# 稲門祭2026 iPadセルフ受付

会場のiPadで使う受付用Webアプリです。参加費は1人1,000円、体験は20分、当日の参加上限は20名です。記録はこの端末のブラウザ内に保存され、他端末とは同期しません。現在は現金受付を基本として使います。

- 公開URL: https://nabe0930.github.io/tomonsai-2026-ipad-kiosk/
- 現金: 当日、空きがある場合に運営者が受領後に登録
- PayPay: 初期状態では無効。加盟店契約と会場利用承認後、会場の公式紙QRまたはPayPay for BusinessアプリのQR画面で来場者が支払い、運営者が取引完了を確認して受付を確定
- 支払い待ちの番号は席を占有します。未入金が確認できた場合に運営者が手動で取り消します。

将来、運営者は会場のiPadに追加したホーム画面アプリの管理画面から、公式店舗QRのPNG/JPEG画像（2MiB以下）を自分で選べます。画像はそのiPad内だけに保存され、管理画面でのみプレビューできます。来場者画面には表示されず、PayPay受付を自動で有効にしません。JSON/CSV控えにも画像は含まれず、別端末へ同期されません。端末を替えた場合は再登録が必要です。

このアプリはPayPayへ決済を送信せず、自動で入金を判定しません。加盟店QRの画像やAPI秘密情報をGitHub・公開サイトには置きません。実際の支払いには会場で掲示する公式紙QRかPayPay for BusinessアプリのQR画面を使います。運用手順は別途配布した導入ガイドを参照してください。
