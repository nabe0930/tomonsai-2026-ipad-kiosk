# 稲門祭2026 iPadセルフ受付

会場のiPadで使う受付用Webアプリです。参加費は1人1,000円、体験は20分、当日の参加上限は20名です。記録はこの端末のブラウザ内に保存され、他端末とは同期しません。

- 公開URL: https://nabe0930.github.io/tomonsai-2026-ipad-kiosk/
- 現金: 当日、空きがある場合に運営者が受領後に登録
- PayPay: 初期状態では無効。加盟店契約と会場利用承認後、会場の公式紙QRで来場者が支払い、運営者がPayPay for Businessで取引完了を確認して受付を確定
- 支払い待ちの番号は席を占有します。未入金が確認できた場合に運営者が手動で取り消します。

このアプリはPayPayへ決済を送信せず、自動で入金を判定しません。加盟店QRやAPI秘密情報はこのリポジトリに保存しません。運用手順は別途配布した導入ガイドを参照してください。
