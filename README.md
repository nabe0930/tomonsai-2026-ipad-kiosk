# 稲門祭2026 iPadセルフ受付

会場のiPadで使う受付用Webアプリです。参加費は1人1,000円、体験は20分、参加上限は20名です。日付と現在時刻による受付制限はなく、運営者が受付を開き、定員に空きがあればいつでも操作できます。枠時刻は体験予定の表示として残ります。記録はこの端末のブラウザ内に保存され、他端末とは同期しません。現在は現金受付を基本として使います。

- 公開URL: https://nabe0930.github.io/tomonsai-2026-ipad-kiosk/
- 現金: 当日、空きがある場合に運営者が受領後に登録
- PayPay: 初期状態では無効。加盟店契約と会場利用承認後、会場の公式紙QRまたはPayPay for BusinessアプリのQR画面で来場者が支払い、運営者が取引完了を確認して受付を確定
- 支払い待ちの番号は席を占有します。未入金が確認できた場合に運営者が手動で取り消します。

## いつでも練習する

- 練習URL: https://nabe0930.github.io/tomonsai-2026-ipad-kiosk/?mode=test&v=7
- 本番の運営者画面からも練習モードを開けます。画面上部の「練習」の表示を確認してください。実際のお金を受け取る必要はありません。
- 「運営者用」を開き、練習専用PIN **000000** で入り、現金受付を登録します。受領確認は練習として操作します。来場者画面から現金受付は確定できません。
- 練習は受付開始済み・在室上限8名で始まります。「練習の受付記録をリセット」で練習記録だけを初期化できます。
- 練習の受付記録・PIN・QR画像は本番と別の端末内保存領域を使います。本番の記録とPINは変わりません。本番へ戻るリンクから切り替えてください。
- 練習JSONは `purpose: test` を付け、練習と本番の間で復元できないようにしています。書き出し名には書き出した日の年月日を使い、練習のファイルには「練習」を付けます。
- 本番の記録は日付が変わっても自動で消えません。開催日や現在時刻を変えてテストする必要はありません。

## 将来のPayPay

将来、運営者は会場のiPadに追加したホーム画面アプリの管理画面から、公式店舗QRのPNG/JPEG画像（2MiB以下）を自分で選べます。画像はそのiPad内だけに保存され、管理画面でのみプレビューできます。来場者画面には表示されず、PayPay受付を自動で有効にしません。JSON/CSV控えにも画像は含まれず、別端末へ同期されません。端末を替えた場合は再登録が必要です。

このアプリはPayPayへ決済を送信せず、自動で入金を判定しません。加盟店QRの画像やAPI秘密情報をGitHub・公開サイトには置きません。実際の支払いには会場で掲示する公式紙QRかPayPay for BusinessアプリのQR画面を使います。運用手順は別途配布した導入ガイドを参照してください。
